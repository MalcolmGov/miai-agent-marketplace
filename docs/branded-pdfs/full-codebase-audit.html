05 Authentication & Security Gating Policy

Triple-Boundary Access Control:
  • Public Allowlist: Strictly scoped to operational probes (/api/health, /api/health/live) and static consent endpoints.
  • Enterprise OIDC Bearer Authentication: Verified by resolveAuth() using JSON Web Key Sets (JWKS) against Microsoft Entra ID or external OIDC issuers.
  • Dual Cookie Partitioning: Separates business workspace sessions from consumer assistant sessions, cryptographically preventing privilege elevation between administrative tools and consumer chats.
