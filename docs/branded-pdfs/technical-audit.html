03 Application Hardening & Boot Failsafes

The application incorporates strict boot-time validation (apps/web/src/lib/security-flags.ts) ensuring the server immediately halts in production if any security boundary is breached:
Security GuardProduction RequirementFail-Closed Behavior
Secret Entropy Floor Signing secrets (OAUTH_TOKEN_SECRET, OAUTH_STATE_SECRET, EMBED_KEY_SECRET) require ≥ 32 characters of high-entropy randomness. Process exits immediately on boot if weak or default.
Production Mock-Rails Blocker Mock authentication, mock wallets, and mock model gateway are strictly blocked when NODE_ENV=production. Boot fails unless explicit dual-ACK flags are set (staging only).
Sandbox Leak Guard Detects if SANDBOX_MODE=1 is accidentally configured alongside real OIDC, live DB, or payment keys. Server halts with error log; prevents live credential exposure.
CSRF & Replay Prevention Connector OAuth flows use single-use cryptographic nonces verified on callback. Nonces are burned on first use; replay attempts rejected.

04 AI Safety, Input/Output Scrubbers & Prompt Defense

Control LayerMechanismProtection Guarantee
PAN / Credit Card Scrubber Luhn algorithm verification runs on both user input and model output streams. Valid 13-19 digit card numbers are automatically redacted.
OTP / 2FA Code Scrubber Regex patterns match one-time passwords, access codes, and banking verification tokens. Model completions cannot echo or leak sensitive auth codes.
Untrusted Delimiter Fencing External knowledge bases and connector tool outputs are wrapped in UNTRUSTED markers. Model is instructed to treat external data as untrusted text, neutralizing indirect prompt injection attacks.
Safety Emergency Classifier Classifies high-risk queries (self-harm, physical hazards, medical emergencies) pre-inference. Routes to official emergency handoff resources without generating uncontrolled LLM responses.

08 Partner Technical Team Deployment Checklist

  • Azure Resource Group: Create targeted resource group (e.g. miai-agents-rg in East US / South Africa North).
  • Deploy Bicep Landing Zone: Run az deployment group create -g miai-agents-rg -f infra/azure/main.bicep -p @parameters.json.
  • Generate Stable Signing Secrets: Generate 32+ character hex secrets for OAUTH_TOKEN_SECRET, OAUTH_STATE_SECRET, and EMBED_KEY_SECRET once and persist in Key Vault.
  • Populate Key Vault: Ensure database connection strings, wallet API keys, and model gateway credentials are set.
  • Configure DNS / Front Door: Map production domain (e.g. agents.myinstantai.com) to Container App Ingress FQDN.
  • Verify Health: Query curl -fsS https://agents.myinstantai.com/api/health — verify all modes show production status (mockRailsAllowed: false).
