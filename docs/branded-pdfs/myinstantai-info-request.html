00 Purpose & how to respond

The app fails closed at boot if production config is incomplete — so every row below is a specific value or confirmation we need from your side (Azure, identity, billing, model, Key Vault, DNS). Fill the “Your response” column or mark ⏳ pending / ✅ ready.
⚠️ Do not paste live secrets into this document. Load secret values (client secrets, API keys, connection strings) directly into the deployment’s Azure Key Vault and mark the row loaded → <name>, or share via a secure channel. Non-secret values (URLs, issuer, deployment names, regions) can be filled in here directly.
